## jQuery Advanced

This project is about learning to use jQuery.

* [db.json](https://github.com/Gwendal/holbertonschool-web_front_end/tree/main/JQuery_advanced/db.json), a simple JSON database file.

* [package.json](https://github.com/Gwendal/holbertonschool-web_front_end/tree/main/JQuery_advanced/package.json), the package file.

* [0-index.html](https://github.com/Gwendal/holbertonschool-web_front_end/tree/main/JQuery_advanced/0-index.html), a script loading jQuery and checking its status.

* [1-index.html](https://github.com/Gwendal/holbertonschool-web_front_end/tree/main/JQuery_advanced/1-index.html), a script creating a paragraph.

* [2-index.html](https://github.com/Gwendal/holbertonschool-web_front_end/tree/main/JQuery_advanced/2-index.html), a script creating a table.

* [3-index.html](https://github.com/Gwendal/holbertonschool-web_front_end/tree/main/JQuery_advanced/3-index.html), a script creating a table by chaining elements.

* [4-index.html](https://github.com/Gwendal/holbertonschool-web_front_end/tree/main/JQuery_advanced/4-index.html), a script creating a table and replacing its content.

* [5-index.html](https://github.com/Gwendal/holbertonschool-web_front_end/tree/main/JQuery_advanced/5-index.html), a script creating a table with a row deletion button.

* [6-index.html](https://github.com/Gwendal/holbertonschool-web_front_end/tree/main/JQuery_advanced/6-index.html), a script with a form to insert rows in a table.

* [7-index.html](https://github.com/Gwendal/holbertonschool-web_front_end/tree/main/JQuery_advanced/7-index.html), a script to query Wikipedia.

* [8-index.html](https://github.com/Gwendal/holbertonschool-web_front_end/tree/main/JQuery_advanced/8-index.html), a script to query Wikipedia with paginated results.

* [9-index.html](https://github.com/Gwendal/holbertonschool-web_front_end/tree/main/JQuery_advanced/9-index.html), a script a script to query Wikipedia with a loading state.

* [10-index.html](https://github.com/Gwendal/holbertonschool-web_front_end/tree/main/JQuery_advanced/10-index.html), a script retrieving and displaying posts from `json-server`.

* [11-index.html](https://github.com/Gwendal/holbertonschool-web_front_end/tree/main/JQuery_advanced/11-index.html), a script with a form to make POST requests to `json-server`.

* [12-index.html](https://github.com/Gwendal/holbertonschool-web_front_end/tree/main/JQuery_advanced/12-index.html), a script with a form to make DELETE requests to `json-server`.
