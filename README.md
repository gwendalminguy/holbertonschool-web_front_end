## Web Front-End

This repository focuses on front-end web development concepts.

* [HTML Advanced](html_advanced/), a project to learn about HTML.

* [CSS Advanced](CSS_advanced/), a project to learn about CSS.

* [SASS & SCSS](sass_scss/), a project to learn about using SASS & SCSS.

* [Developer Tools](developer_tools/), a project to learn about using browser developer tools.

* [Flexbox](flexbox/), a project to learn about manipulating flexbox properties.

* [Forms](form/), a project to learn about implementing forms.

* [Responsive Design](responsive_design/), a project to learn about responsive design.

* [Accessibility](accessibility/), a project to learn about accessibility.

* [Bootstrap](Bootstrap/), a project to learn about using Bootstrap.

* [JavaScript Advanced](Javascript_advanced/), a project to learn about JavaScript.

* [jQuery Advanced](JQuery_advanced/), a project to learn about using jQuery.

* [Cookies - Local Storage](Cookies_local_storage/), a project to learn about using cookies and local/session storage.
