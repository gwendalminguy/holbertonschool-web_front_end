## Web Front-End

This repository focuses on front-end web development concepts.

* [HTML Advanced](https://github.com/gwendalminguy/holbertonschool-web_front_end/blob/main/html_advanced), a project to learn about HTML.

* [CSS Advanced](https://github.com/gwendalminguy/holbertonschool-web_front_end/blob/main/CSS_advanced), a project to learn about CSS.

* [SASS & SCSS](https://github.com/gwendalminguy/holbertonschool-web_front_end/blob/main/sass_scss), a project to learn about using SASS & SCSS.

* [Developer Tools](https://github.com/gwendalminguy/holbertonschool-web_front_end/blob/main/developer_tools), a project to learn about using browser developer tools.

* [Flexbox](https://github.com/gwendalminguy/holbertonschool-web_front_end/blob/main/flexbox), a project to learn about manipulating flexbox properties.

* [Forms](https://github.com/gwendalminguy/holbertonschool-web_front_end/blob/main/form), a project to learn about implementing forms.

* [Responsive Design](https://github.com/gwendalminguy/holbertonschool-web_front_end/blob/main/responsive_design), a project to learn about responsive design.

* [Accessibility](https://github.com/gwendalminguy/holbertonschool-web_front_end/blob/main/accessibility), a project to learn about accessibility.

* [Bootstrap](https://github.com/gwendalminguy/holbertonschool-web_front_end/blob/main/Bootstrap), a project to learn about using Bootstrap.

* [JavaScript Advanced](https://github.com/gwendalminguy/holbertonschool-web_front_end/blob/main/Javascript_advanced), a project to learn about JavaScript.

* [jQuery Advanced](https://github.com/gwendalminguy/holbertonschool-web_front_end/blob/main/JQuery_advanced), a project to learn about using jQuery.
