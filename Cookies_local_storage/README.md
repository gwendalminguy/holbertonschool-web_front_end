## Cookies & Local Storage

This project is about learning to cookies and local storage.

* [0-index.html](https://github.com/gwendalminguy/holbertonschool-web_front_end/tree/main/Cookies_local_storage/0-index.html), an HTML file with a basic form and buttons to set and retrieve cookies.

* [1-index.html](https://github.com/gwendalminguy/holbertonschool-web_front_end/tree/main/Cookies_local_storage/1-index.html), an HTML file with a basic form and buttons to set and retrieve cookies with a 10 days expiration.

* [2-index.html](https://github.com/gwendalminguy/holbertonschool-web_front_end/tree/main/Cookies_local_storage/2-index.html), an HTML file with a basic form and buttons to set and retrieve cookies, using a dedicated function to use the name of the cookie.

* [3-index.html](https://github.com/gwendalminguy/holbertonschool-web_front_end/tree/main/Cookies_local_storage/3-index.html), an HTML file with a login form, a welcome message and a logout button.

* [4-index.html](https://github.com/gwendalminguy/holbertonschool-web_front_end/tree/main/Cookies_local_storage/4-index.html), an HTML file with a login form, a welcome message and a logout button, using `js-cookie`.

* [5-index.html](https://github.com/gwendalminguy/holbertonschool-web_front_end/tree/main/Cookies_local_storage/5-index.html), an HTML file with a simple shopping cart using local storage.

* [6-index.html](https://github.com/gwendalminguy/holbertonschool-web_front_end/tree/main/Cookies_local_storage/6-index.html), an HTML file with a simple shopping cart using session storage.

* [7-index.html](https://github.com/gwendalminguy/holbertonschool-web_front_end/tree/main/Cookies_local_storage/7-index.html), an HTML file with a more elaborate shopping cart using session storage.
