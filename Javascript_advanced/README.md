## JavaScript Advanced

This project is about working with advanced JavaScript concepts.

* [0-welcome.js](https://github.com/Gwendal/holbertonschool-web_front_end/tree/main/Javascript_advanced/0-welcome.js), a script displaying a welcome message.

* [1-nested_functions.js](https://github.com/Gwendal/holbertonschool-web_front_end/tree/main/Javascript_advanced/1-nested_functions.js), a script displaying three successive welcome messages.

* [2-function_me.js](https://github.com/Gwendal/holbertonschool-web_front_end/tree/main/Javascript_advanced/2-function_me.js), a script displaying a welcome message dynamically.

* [3-classrooms.js](https://github.com/Gwendal/holbertonschool-web_front_end/tree/main/Javascript_advanced/3-classrooms.js), a script manipulating an array using closure.

* [4-math.js](https://github.com/Gwendal/holbertonschool-web_front_end/tree/main/Javascript_advanced/4-math.js), a script making operations using closure.

* [5-mode.js](https://github.com/Gwendal/holbertonschool-web_front_end/tree/main/Javascript_advanced/5-mode.js), a script changing the page theme using closure.

* [6-hogwarts.js](https://github.com/Gwendal/holbertonschool-web_front_end/tree/main/Javascript_advanced/6-hogwarts.js), a script manipulating class instances with public and private methods.

* [7-timeout.js](https://github.com/Gwendal/holbertonschool-web_front_end/tree/main/Javascript_advanced/7-timeout.js), a script manipulating the stack order of operations.

* [8-payments.js](https://github.com/Gwendal/holbertonschool-web_front_end/tree/main/Javascript_advanced/8-payments.js), a script manipulating the stack order of functions calls.

* [9-prime.js](https://github.com/Gwendal/holbertonschool-web_front_end/tree/main/Javascript_advanced/9-prime.js), a script counting prime numbers and logging the execution timing.

* [10-prime.js](https://github.com/Gwendal/holbertonschool-web_front_end/tree/main/Javascript_advanced/10-prime.js), a script counting prime numbers 100 times and logging the execution timing.

* [11-prime.js](https://github.com/Gwendal/holbertonschool-web_front_end/tree/main/Javascript_advanced/11-prime.js), a script counting prime numbers 100 times and changing the stack order.

* [12-room_area.js](https://github.com/Gwendal/holbertonschool-web_front_end/tree/main/Javascript_advanced/12-room_area.js), a script computing room dimensions with binding.

* [13-bind_user.js](https://github.com/Gwendal/holbertonschool-web_front_end/tree/main/Javascript_advanced/13-bind_user.js), a script displaying a welcome message using closure and binding.

* [14-wikipedia.js](https://github.com/Gwendal/holbertonschool-web_front_end/tree/main/Javascript_advanced/14-wikipedia.js), a script querying Wikipedia and displaying the result using a callback function.

* [100-stock.js](https://github.com/Gwendal/holbertonschool-web_front_end/tree/main/Javascript_advanced/14-stock.js), a script processing user input and checking product stock to call the right callback function.
